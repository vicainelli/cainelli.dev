I write notes in Markdown first. Always have. So when a thought has to become a Jira ticket, I hit the same wall every time: Jira doesn't speak Markdown.

The worst part isn't the headings or the lists. It's inline code. A backtick in Markdown is fast; `{{double curly brackets}}` in Jira feel like typing through molasses. I built [markdown2jira](https://markdown2jira.cainelli.dev/) so I could stop doing that translation by hand.
